There are 9 status ailments in the game. They are written down in damage slots, and go as follows:

| **Status**  | Description                       |
| :---------- | :-------------------------------- |
| **Undo**    | *Unable to heal.*                 |
| **Stun**    | *Unable to move.*                 |
| **Blight**  | *Unable to use abilities.*        |
| **Hex**     | *Unable to cast spells.*          |
| **Stress**  | *Unable to clear strain.*         |
| **Bleed**   | *+1 minor damage with each roll.* |
| **Wither**  | *+1 flesh strain with each roll.* |
| **Despair** | *+1 soul strain with each roll.*  |
| **Fog**     | *All Act ranks are set to 0.*     |
Statuses are written in alongside a number that indicates how many rolls they last.
