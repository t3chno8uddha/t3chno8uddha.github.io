There are twelve Acts in the game, each belonging to one of four Traits.

|              | **Physical**                     | Quality      |
| -----------: | -------------------------------- | :----------- |
|    **Force** | *Move, bend, hurt.*              | ***Direct*** |
|   **Endure** | *Withstand, outlast, persist.*   | ***Still***  |
| **Maneuver** | *Evade, finesse, fool.*          | ***Agile***  |
|              |                                  |              |
|              | **Mental**                       |              |
|     **Hunt** | *Track, scan, outwit.*           | ***Direct*** |
|   **Reason** | *Analyze, recall, deduce.*       | ***Still***  |
|   **Tinker** | *Craft, devise, theorize.*       | ***Agile***  |
|              |                                  |              |
|              | **Spiritual**                    |              |
|     **Ruin** | *Annihilate, destroy, unmake.*   | ***Direct*** |
|     **Form** | *Conjure, create, summon.*       | ***Still***  |
|    **Alter** | *Warp, transmute, change.*       | ***Agile***  |
|              |                                  |              |
|              | **Social**                       |              |
|     **Sway** | *Persuade, charm, seduce.*       | ***Direct*** |
|  **Command** | *Intimidate, lead, impose.*      | ***Still***  |
|  **Perform** | *Captivate, express, embellish.* | ***Agile***  |

Each Act holds a rating between 0 and 5. That rating is your dice pool while performing the given Act.

Every time the players perform an Act at grave Peril, they mark 1 xp for that Act's Trait.
After a session ends, players also mark 1 xp (for their character or Trait) if they've met the following conditions:
- *If they've addressed a challenge with their heritage's or archetype's strengths.*
- *If they've rolled a critical success.*
- *If they've performed a group action.*

There are two experience tracks - Trait xp and character xp.
6 marks in Trait xp result in said Trait leveling up. The player ranks one of the Trait's Acts up.
8 marks in character xp result in the character leveling up. The player gains 1♥ toward an ability.
